# Online Cinema Ticket Booking System Backend

This is a Java-based backend project for an online cinema ticket booking system using Spring Framework.

## Features
- User registration and authentication
- Movie listing and details
- Show timing and seat management
- Ticket booking and cancellation
- Admin interface for managing movies and shows

## Technologies
- Java 93.6%
- HTML 6.3%
- Docker 0.1%
- Spring Framework
- MySQL or any relational database
- Maven (pom.xml)
